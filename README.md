# CRUD-Final

**Author:** Roshjens Kunwar

**Course:** IT Security Management and DevOps

## Project Description

A CRUD REST API built with ASP.NET Core and C#,
using MariaDB as the database.

The application will be containerized using Docker
and deployed on Kubernetes using Minikube.

## Technologies

- C#
- ASP.NET Core (.NET 10)
- MariaDB
- Docker
- Docker Compose
- Kubernetes
- Minikube
- k6

## Features

- Create items
- Read items
- Update items
- Delete items
- Health monitoring
- Container deployment
- Kubernetes orchestration
- Load testing
